  • เครื่องประดับ 1–2 ชิ้น
  • ไม่มี pattern บนชุด หรือมีน้อย
  • ไม่มีปีก / เขา / หางซับซ้อน

🧝

  • เครื่องประดับ / อุปกรณ์หลายชิ้น
  • ปีก · เขา · หาง · armor ดีเทลสูง
  • เอฟเฟกต์เวทมนตร์ หรือกลไก

  • ใช้เป็น profile picture หรือ avatar
  • โพสต์ลง SNS ส่วนตัว (IG, Twitter, FB)
  • ใช้ตกแต่งของใช้ส่วนตัว ไม่หาเงิน
  • ห้ามนำไปขายต่อหรือใช้ในนามองค์กร
🎁 Giveaway +20%
  • แจกในกิจกรรมออนไลน์ / stream
  • รางวัลใน community ที่ไม่ได้รับเงิน
  • โปรโมทช่องหรือเพจของตัวเองได้
  • ไม่ใช่เพื่อนำไปขายหรือใช้แบรนด์บริษัท
🏪 เชิงพาณิชย์ (Commercial) +50%
  • ใช้ใน merchandise ที่นำไปขาย (สติ๊กเกอร์, เสื้อ ฯลฯ)
  • เป็นโลโก้หรือ mascot ของแบรนด์บุคคล
  • ใช้โปรโมทธุรกิจขนาดเล็ก / freelance
  • รายได้จากงานไม่เกิน 1 ล้านบาท/ปี
🏢 สิทธิ์ขาด / บริษัท (Exclusive) ติดต่อโดยตรง
  • โอนลิขสิทธิ์ทั้งหมดให้ผู้ว่าจ้าง
  • ใช้ในนามบริษัทหรือองค์กร
  • ใช้ใน campaign โฆษณา / สื่อกว้าง
  • ราคาขึ้นอยู่กับขอบเขตการใช้งาน — ต้องทักคุย
